[HEADING=1]not-k8s: replaced kubelet with a 15MB Rust agent, profiled on a Pixel 7[/HEADING]

[B]nodelet[/B] — drop-in kubelet replacement, Rust, event-driven instead of polling. Same control plane, same kubectl, same CRDs.

Idle, no pods, 120s, 3 replicates each:

[LIST]
[*][B]x86_64[/B] — nodelet 15MB / 0.08s CPU, kubelet 81MB / 0.85s CPU
[*][B]Pixel 7[/B] — nodelet 12MB / 0.44s CPU, kubelet 68MB / 8.03s CPU
[/LIST]

CPU gap widens from 10.6x to 18.4x on the slower core, memory doesn't. Cache, the in-order A55, or Go's GC — can't tell, no hardware counters in the VM.

The k3s control plane on that phone idles at ~34% of a core and ~350MB, more than either agent.
