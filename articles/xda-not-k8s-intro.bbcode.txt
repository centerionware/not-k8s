[HEADING=1]not-k8s: replaced kubelet with a 15MB Rust agent[/HEADING]

Been building this for a while — a real Kubernetes control plane (real apiserver, real scheduler, full kubectl/CRD support) with kubelet swapped out for [B]nodelet[/B], a leaner event-driven agent written in Rust.

Benchmarked it against a genuine unmodified upstream kubelet, both completely idle, same control plane, six separate runs so I couldn't bias the numbers:

[LIST]
[*][B]Memory[/B] — ~15MB nodelet vs ~81MB kubelet
[*][B]CPU (2min idle)[/B] — ~0.08s nodelet vs ~0.85s kubelet
[/LIST]
